# UX Project Scenario — MediCare Hospital Appointment App

## AIM

To design a user-centered hospital appointment booking application by identifying user problems, generating UX solutions through ideation, creating user stories and scenarios, developing task flows, and organizing healthcare services using information architecture.

---

## PROJECT SCENARIO

### MediCare — Hospital Appointment Booking App

MediCare is a mobile application that allows patients to search for doctors, select medical specialties, check available appointment slots, book consultations, and manage their appointments online.

Patients often face difficulties when booking appointments through traditional hospital systems. They may need to make phone calls, wait for confirmation, or visit the hospital to check doctor availability. MediCare aims to make the complete appointment-booking process simple, quick, and accessible.

---

# 1. SOLUTION IDEATION

## UX Problem

Patients need a simple way to find the right doctor and book an appointment because existing appointment systems may involve multiple steps, unclear doctor availability, and long waiting times.

### Ideation Method — Crazy 8s

A **Crazy 8s** ideation exercise was conducted to generate multiple possible solutions quickly.

### Crazy 8s Ideas

| No. | Low-Fidelity Idea |
|---|---|
| 1 | **Quick Appointment** – Book an appointment directly from the home screen. |
| 2 | **Doctor Search** – Search doctors by name, specialty, or department. |
| 3 | **Smart Suggestions** – Recommend doctors based on the selected specialty. |
| 4 | **Available Slots** – Clearly display available dates and time slots. |
| 5 | **Nearby Hospitals** – Find nearby hospitals and doctors. |
| 6 | **Previous Doctors** – Quickly book with previously consulted doctors. |
| 7 | **Appointment Reminder** – Send reminders before appointments. |
| 8 | **Emergency Access** – Provide quick access to emergency services. |

### Selected Solution

The final concept combines:

**Quick Appointment + Doctor Search + Available Slots + Appointment Reminder**

This solution reduces unnecessary steps and allows patients to complete appointment booking quickly.

# 2. CREATING USER STORIES

## User Persona

**Name:** Kavya Menon  
**Age:** 26  
**Occupation:** Marketing Executive  

**Goal:** Book a doctor's appointment quickly without calling the hospital.

### User Stories

1. **As a patient, I want to search for doctors by specialty, so that I can find a suitable doctor quickly.**

2. **As a patient, I want to view doctor profiles, so that I can check their qualifications and experience before booking.**

3. **As a patient, I want to see available appointment slots, so that I can choose a convenient date and time.**

4. **As a patient, I want to book an appointment online, so that I can avoid waiting at the hospital reception.**

5. **As a patient, I want to receive appointment reminders, so that I do not forget my scheduled consultation.**

6. **As a patient, I want to view my previous appointments, so that I can keep track of my medical visits.**

7. **As a patient, I want to cancel or reschedule an appointment, so that I can manage unexpected changes in my schedule.**

# 3. CREATING SCENARIOS

## Selected User Story

> **As a patient, I want to see available appointment slots, so that I can choose a convenient date and time.**

### Narrative Scenario

Kavya is a 26-year-old marketing executive with a busy work schedule. She needs to consult a doctor but does not want to spend time calling different hospitals to check availability.

During her lunch break, Kavya opens the MediCare application on her smartphone. She searches for a suitable medical specialty and views a list of available doctors. After selecting a doctor, she checks the doctor's profile and available appointment slots.

Kavya finds a suitable time after work and selects the appointment. She reviews the booking information and confirms the appointment. The application immediately displays a confirmation message and sends her an appointment reminder.

### Emotional States

| Stage | Emotional State |
|---|---|
| Before opening the app | Worried and slightly stressed |
| Searching for a doctor | Focused |
| Finding an available slot | Relieved |
| Confirming the appointment | Confident |
| Receiving confirmation | Satisfied |

### Environment

- **Location:** Office
- **Device:** Smartphone
- **Situation:** Lunch break
- **Available Time:** Limited
- **Internet:** Mobile Data / Wi-Fi

### Tasks

1. Open MediCare app.
2. Search for a medical specialty.
3. Select a doctor.
4. View doctor profile.
5. Check available slots.
6. Select date and time.
7. Review appointment.
8. Confirm booking.
9. Receive confirmation and reminder.
